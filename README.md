# HR_Analysis
# HR Analytics - Employee Attrition Prediction

## Project Overview

This project focuses on analyzing employee attrition and predicting whether an employee is likely to leave the organization. The project uses machine learning techniques and data visualization tools to identify key factors affecting employee turnover.

## Objective

* Analyze employee attrition trends.
* Identify factors contributing to employee resignation.
* Build a predictive machine learning model.
* Create an interactive Power BI dashboard for HR insights.

## Dataset

IBM HR Analytics Employee Attrition Dataset

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn
* Power BI
* Jupyter Notebook

## Project Workflow

### 1. Data Collection

Imported the HR employee attrition dataset.

### 2. Data Cleaning

* Checked missing values
* Removed inconsistencies
* Encoded categorical variables

### 3. Exploratory Data Analysis (EDA)

* Attrition Distribution
* Department-wise Attrition
* Age Analysis
* Daily Rate Analysis

### 4. Machine Learning Model

Model Used:

* Logistic Regression

### 5. Model Evaluation

Metrics:

* Accuracy Score
* Confusion Matrix
* Classification Report

### 6. Dashboard Development

Created an interactive Power BI dashboard including:

* Total Employees
* Employees Left
* Attrition Distribution
* Department Analysis
* Age Distribution
* Education Analysis

## Results

The Logistic Regression model successfully predicted employee attrition and provided useful insights into workforce behavior. The dashboard helps HR teams understand attrition trends and make data-driven decisions.
